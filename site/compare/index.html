Where the others are ahead

  • Users and time. AeroSpace has existed since 2023 and has 23,250 stars; Omacosy has 665 stars and a Show HN. Omac's public repository was created two days before these facts were read, and has no stars yet.6,7,8,10,66
  • Open source. Omacosy's and AeroSpace's code is public, under the MIT license. Omac's app source is private.3,4,5
  • Intel Macs and older macOS. AeroSpace is a universal app for macOS 13 or later. Omac needs Apple silicon and has been tested by hand only on macOS 26.52,54,56,57
  • The rest of the desktop. Omacosy adds a status bar, a workspace overview with live previews and 4-finger swipes. Omac has only a small workspace bar.42,43
  • Uninstall and updates. Omacosy's uninstall script restores the macOS settings it changed, and omacosy-update updates it; AeroSpace updates through Homebrew. Omac's uninstall is a list of commands, and it has no in-app updater yet.61,62,63,64,65
  • Privacy, written down. Omacosy publishes a table of the permissions it asks for and a no-telemetry statement. Omac's public README has neither yet.67,68,69
  • Left ⌘ stays yours elsewhere. Omac takes 83 Left ⌘ chords: Left ⌘ with 1–0, the arrows, Return, K, J, − and =; with Shift, the arrows, 1–0, Return, Space, N, F, L, R, − and =; with ⌥, Space, F, G, − and =; and 37 more with Ctrl or two modifiers. Only Left ⌘ with the arrows can be handed back to text fields, so Left ⌘ Shift ← and →, which select to the start or end of a line, swap windows there too. Those app shortcuts move to Right ⌘. mattvv's omarchy-mac uses ⌥ as its Super key instead, so ⌘1–9 keep working.70,71
  • The real thing. Try Omarchy and Omarchy Mac, both from the Omarchy organisation, run Omarchy itself, with every feature and no port gaps.72,73

Where Omac differs

  • One app, nothing else to install: no Homebrew, no developer tools, no driver extension and no other apps. Omacosy installs 14 packages and compiles 7 helpers.12,13,14,18
  • All four of Omarchy's key layers, with 42 default keys on Super+Ctrl or Super+Alt, though 14 Omarchy keys that macOS already uses move to other chords or are left to macOS. Omacosy keeps two layers, and AeroSpace cannot bind Left ⌘ apart from Right ⌘.32,33,34,35
  • The installer changes no macOS setting beyond adding a login item. A theme switches light or dark mode only when you pick one, though turning themes off leaves that mode as it is. Omacosy's installer auto-hides the menu bar and turns off gestures.11,27,28
  • Notarized by Apple since 1.4.8, as Try Omarchy is, and OmniWM, Omacosy's second window manager option. AeroSpace is not notarized.29,51,74,75
  • A Developer ID signature, which the curl installer checks before installing. AeroSpace is self-signed with no Team ID and is not notarized, so its Homebrew cask removes the download's quarantine flag; Omac's tap installs the notarized app as it is.19,29,47,48,50
  • All 22 Omarchy themes built in, against Omacosy's 4.37,38
  • Small: a 3.5 MB download.58

Other ways to get Omarchy on a Mac

  • Try Omarchy. From the Omarchy organisation, and linked from omarchy.org as "Try on Mac". It runs the real Omarchy in a virtual machine app. Signed and notarized; a 1.44 GB download; needs Apple silicon, macOS 15 or later and 8 GB free.72,74,76,77,78
  • Omarchy Mac. Also from the Omarchy organisation: Omarchy on Asahi Linux, installed alongside macOS on an M1 or M2 with 50 GB free. Omarchy's manual supports Intel Macs by replacing macOS.73,79,80
  • mattvv/omarchy-mac. AeroSpace, SketchyBar and JankyBorders with 22 themes. Needs Homebrew; uses ⌥ as its Super key.71,81,82
  • Omachy. Installs 22 tools through Homebrew, AeroSpace and SketchyBar among them. Needs Homebrew and the Command Line Tools first, and macOS 13 or later.83,84
  • omarchy4mac. Installs the Command Line Tools and Homebrew if missing, then 18 packages, AeroSpace and SketchyBar among them.85
