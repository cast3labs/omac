Install Omac

One app. Nothing else to install. Needs a Mac with Apple silicon and macOS 14 or later — no Homebrew, no developer tools, no GitHub account.

1. Terminal (curl)

The way that sets up everything: the app in ~/Applications, the omac command, and start at login. Paste it into Terminal (⌘ Space, type Terminal, press Return):

curl -fsSL https://raw.githubusercontent.com/evanscastonguay/omac/main/install.sh | bash

Prefer to read the script first? Download it, read it, then run it:

curl -fsSL https://raw.githubusercontent.com/evanscastonguay/omac/main/install.sh -o install.sh
less install.sh
bash install.sh

The installer checks the app's Developer ID signature before installing it, and stops, changing nothing, on an Intel Mac or when another package manager installed Omac. If an old copy of Omac is in /Applications, Terminal asks for your Mac password to remove it: two copies conflict. The terms of use are here; the installer prints their address too.

2. Homebrew

brew install --cask evanscastonguay/tap/omac, then open ~/Applications/Omac.app. The cask does not start Omac or turn on start at login; omac login on does that.

brew install --cask evanscastonguay/tap/omac
open ~/Applications/Omac.app

3. Download

Omac-arm64.zip from the latest release; drag Omac.app into Applications. Then open it: macOS asks once whether to open an app downloaded from the internet — click Open. This way does not set up the omac command or start at login. The download page walks through it.

Let Omac control your windows

Whatever the way, first grant System Settings → Privacy & Security → Accessibility → Omac, then omac status must show accessibility and tap both true. Only the curl way and the tap set up the omac command; the download does not.

omac status

Omac notices the permission within two seconds — no restart needed. Then press Left ⌘ K for every shortcut, or read getting started.

Requirements

  • A Mac with Apple silicon (M1 or later). Intel Macs are not supported; the installer stops on one.
  • macOS 14 or later. Tested by hand on macOS 26; macOS 14 and 15 are allowed, and an automated check installs and starts Omac on both.
  • The Accessibility permission, which you grant once (above). Omac needs no change to System Integrity Protection and installs nothing else.

Omac never sends anything without asking: your settings, your window layout and your clipboard history stay on your Mac.

Signed and notarized

Every release is signed with the author's Apple Developer ID: macOS, and the installer, check that the app was built by that identity and has not been changed since. Every release since 1.4.8 is also notarized: Apple scanned the build for malware and issued a ticket, stapled to the app, which macOS can confirm even offline. The Terminal command has no extra step; a copy downloaded with a web browser opens after macOS's usual first-open confirmation. Never turn Gatekeeper off for Omac: it does not need it.

The complete uninstall

The rows above remove the app. To undo everything Omac changed, in this order:

omac theme off          # if you used a theme: restores your wallpaper and the recoloured apps
omac skill uninstall    # if you installed the coding-agent skill: removes the links in ~/.claude, ~/.codex, ~/.pi
omac login off          # stops Omac from starting at login
omac quit

If you ran omac theme adopt, each adopted app keeps the one line adopt added to its config, which you can delete by hand: in Ghostty's config, config-file = ?"~/.local/state/omac/current/theme/ghostty.conf"; in ~/.claude/settings.json, the theme value; in VS Code's settings, workbench.colorTheme when it names omac-theme. Then remove the app the way you installed it (the row above), and:

rm -rf ~/.config/omac ~/.local/state/omac ~/.local/share/omac      # settings, state, downloaded theme media
rm -rf ~/Library/Caches/com.evanscastonguay.omac
defaults delete com.evanscastonguay.omac 2>/dev/null
tccutil reset Accessibility com.evanscastonguay.omac                # the permission grant

The installer may have added two lines starting with # Added by the Omac installer to your shell's startup file (~/.zshrc, ~/.bash_profile or ~/.config/fish/config.fish); delete them. Omac writes no other macOS setting: a theme changes the wallpaper and light/dark mode only when you choose one, and omac theme off restores the wallpaper.
