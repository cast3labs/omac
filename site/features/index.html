What Omac does

47 features on a Mac: Omarchy's, and a few of Omac's own. Most have a default key.

Keys are shown as you press them. Left ⌘ is the Omac key, and Right ⌘ stays a normal ⌘. ⌥ is Option. Every key can be changed in omac.toml.

Windows and workspaces

Dwindle tiling

Each new window splits the space of the one you are in, so tiled windows sit side by side and never overlap.

Virtual workspaces

Ten workspaces across your displays. Each belongs to a display, and switching to one goes to the display that has it.

Left ⌘ 1 … 0

Directional focus

Move the focus to the window on the left, right, above or below, and on to the next display at the edge.

Left ⌘ ← ↑ → ↓

Move / swap window

Swap a window with its neighbour, or move it to the next display when it has no neighbour that way.

Left ⌘ Shift ← ↑ → ↓

Move window to workspace

Send the window to another workspace, and follow it there or stay where you are.

Left ⌘ Shift 1 … 0orLeft ⌘ Shift ⌥ 1 … 0

New windows open where you are

A new window opens on the workspace you are looking at; one opened with a launch key lands where you pressed it.

Multiple displays, followed live

Plug in, unplug or rearrange displays and Omac follows: each display keeps its workspaces and is tiled again.

Resize window

Make a window wider, narrower, taller or shorter. For the width, add ⌥ for a small step or Ctrl for a big one.

Left ⌘ − / =orLeft ⌘ Shift − / =orLeft ⌘ ⌥ − / =orLeft ⌘ Ctrl − / =

Split-direction toggle

Turn a split from side by side to stacked, and back.

Left ⌘ J

Floating toggle

Let a window float freely above the tiles, or put it back in the tiling.

Left ⌘ Shift Space

Full screen and full width

macOS full screen in a Space of its own, or full width: the window fills the screen and keeps the outer gaps.

Left ⌘ Ctrl ForLeft ⌘ ⌥ F

Move workspace between monitors

Move a whole workspace to the display on the left, right, above or below.

Left ⌘ Shift ⌥ ← ↑ → ↓

Cycle displays / windows

Cycle through the windows of a workspace, or move the focus to the next display.

⌥ TaborCtrl ⌥ Tab

Scrolling layout

Switch a workspace to a scrolling row of columns, where a new window never squeezes the others.

Left ⌘ Shift LorLeft ⌘ Shift R

Per-app window rules

Rules per app in omac.toml: always float it, open it on a given workspace, give it a size, or leave it alone.

Full width

The window fills the screen but keeps the outer gaps; the same key puts it back.

Left ⌘ ⌥ F

Pin (stays visible)

Pin a floating window: it stays with you across workspaces, and the tiles make room when it sits against an edge.

Left ⌘ Shift Ctrl O

Window pop

Pop a window out: it floats, centred at 1300×900, and stays with you across workspaces. Press again to tile it.

Left ⌘ Ctrl O

Focus border follows the mouse

Optional: the focus border follows the window under the pointer, without switching apps.

Activate on hover

Optional, off by default: point at a window and type there, no click. The menu has a quick off switch.

Column stacking (scrolling layout)

In the scrolling layout, stack a window into the column beside it, move through the stack, or pop it out.

Left ⌘ Shift Ctrl ← / →orLeft ⌘ ⌥ G

Desktop tools

App launch hotkeys

Open a terminal, a browser, an editor or the file manager: the apps you prefer, or the ones every Mac has.

Left ⌘ ReturnorLeft ⌘ Shift ReturnorLeft ⌘ Shift NorLeft ⌘ Shift F

Command palette

Search your key bindings by name and run one.

Left ⌘ ⌥ Space

Keybinding cheatsheet

Shows every shortcut your own omac.toml binds.

Left ⌘ K

On-screen workspace bar

A small bar on each display shows its workspaces; click a number to switch.

Universal clipboard history

A searchable history of what you copy, text and images. Copies a password manager marks as secret are never kept.

Left ⌘ Ctrl V

Countdown reminders

Set a countdown from the command line. A notification comes when it ends, even if Omac has quit.

omac reminder

Reminder keys

Set a reminder with a key and a few words, see the ones running, or clear them.

Left ⌘ Ctrl RorLeft ⌘ Ctrl ⌥ RorLeft ⌘ Shift Ctrl R

Coding agents and speech

AI coding-agent harness

Opens your AI coding agent in a terminal. Choose the agent from the menu or with omac agent use.

Left ⌘ Shift Ctrl A

Agent skill: your agent configures Omac

Teaches your coding agent how to change Omac's settings and use the omac command safely.

Agent skill installer

Links Omac's skill into the coding agents it finds, such as Claude Code and Codex. Uninstall removes only its links.

omac skill install

Crash reports, explained

Hands the newest macOS crash report to your coding agent to explain in plain words.

omac agent crash

Read aloud

Reads the selected text aloud in your macOS voice; press it again to stop.

⌥ Esc

Dictation

Hold Left Ctrl and fn, talk, and let go: the words are typed where you were. macOS 26; off until you turn it on.

Left Ctrl fnorLeft ⌘ Ctrl X

OCR text extraction

Drag over any part of the screen to copy its text, read on your Mac by macOS's own text recognition.

Left ⌘ Ctrl T

Themes

Theme system (22 themes)

Omarchy's 22 colour themes for Omac, light or dark mode, the wallpaper (20 themes have one) and, if you choose, apps like Ghostty.

Left ⌘ Shift Ctrl Space

Per-theme backgrounds

Cycles the current theme's wallpapers, plus any you add, on every display. Most themes ship one; two ship none.

Left ⌘ Ctrl ⌥ Space

System keys

Keep-awake toggle

Keeps the screen from sleeping until you press the key again or quit Omac.

Left ⌘ Ctrl I

Menu-bar mode indicators

The menu-bar icon shows when tiling is paused, when keep awake, Night Shift, mic mute or reading aloud is on, and while you dictate.

Color picker → clipboard

Click any pixel on the screen to copy its colour as hex, like #1E1E2E.

Left ⌘ Ctrl P

Night Shift toggle hotkey

Turn Night Shift on or off with one key.

Left ⌘ Ctrl N

Mic-mute toggle

Mute the microphone for every app at once, with one key.

Left ⌘ Ctrl M

Screensaver

Shows Omarchy's ASCII art on every display until you press a key or move the mouse. It starts on a key, not on idle yet.

Left ⌘ Ctrl ⌥ S

Settings and control

Single editable config + hot-reload

Every setting in one commented file, ~/.config/omac/omac.toml. Save it and the change applies at once.

Configurable keybindings

Keys are [[bind]] lines in omac.toml: change one, add your own, or unbind a default.

CLI control (headless)

The omac command controls Omac from a terminal or a script: status, keys, pause, themes and more.

omac …

Panic / pause tiling

One key pauses the tiling and leaves windows where they are; press it again to resume. Quitting Omac puts hidden windows back.

Left ⌘ Ctrl ⌥ Esc

Left to macOS

Omarchy is a whole Linux system. These parts of it are already on your Mac, or are outside what a window manager does.

  • Application launcher UI. Left ⌘ Space stays Spotlight, or Raycast if you use it.
  • Notices (clock / battery / weather). The macOS menu bar already shows the clock and the battery.
  • Multi-model AI support. Each coding agent picks its own model; Omac only opens the agent.
  • Do Not Disturb toggle hotkey. A Shortcut that toggles Do Not Disturb can have its own key, set in the Shortcuts app.
  • Reflexes macOS already owns. Volume, brightness, screenshots, screen lock and the emoji picker keep their macOS keys.
  • Bundled dev apps (Neovim, TUIs, …). Omac bundles no other apps. It arranges the windows of the apps you already use.
  • First-class web apps. Safari can add a website to the Dock as an app.
  • Gaming (Steam / Proton / emulation). Outside a window manager: install games the usual Mac way.
  • Windows VM. Outside a window manager: use a Mac virtualization app.
  • Packages / updates / snapshots. macOS updates itself. Omac updates when you run its install command again, or through Homebrew.
  • Encryption / hardware auth / sleep. FileVault, Touch ID and sleep are part of macOS.
  • Install / dual-boot / boot branding. Omac is an app on the macOS you already have: nothing to install at boot.
