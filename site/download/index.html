Download Omac

The Terminal command is the simplest way: it installs the app, the omac command and start at login, and checks the download for you.

curl -fsSL https://raw.githubusercontent.com/cast3labs/omac/main/install.sh | bash

Without Terminal

Download Omac

Version 1.0.1, 2026-10-09. Omac-arm64.zip for Apple silicon · SHA-256 checksum · release notes

  1. Open the zip. A folder appears with Omac.app in it.
  2. Drag Omac.app into Applications.
  3. Open Omac. macOS asks once whether to open an app downloaded from the internet — click Open.
  4. Omac opens its Welcome to Omac window, and a macOS dialog asks to let Omac control your windows. Click Open System Settings in either, then turn Omac on under Privacy & Security → Accessibility. Omac notices within two seconds.
  5. The welcome window also asks two optional questions, both unticked: whether Omac may check for updates automatically, and whether it may send a daily usage count. Tick what you want, or nothing, then click Continue.
  6. Press Left ⌘ K: every shortcut is on screen.

What you will see

Omac is signed with the author's Apple Developer ID and notarized by Apple, so macOS asks once, before the first open, whether to open an app downloaded from the internet, and nothing more. If macOS says instead that it cannot verify the app, you do not have a notarized copy (the latest release is one): delete it and download the latest from Omac's releases. Never turn Gatekeeper off for Omac: it does not need it.

Afterwards

  • Start at login is not set up by the download: choose Launch at login from Omac's menu-bar icon.
  • The omac command is not either: run the Terminal command above once. It moves Omac to ~/Applications, keeps your settings, and sets up the command (macOS may ask for the Accessibility permission again). It does not turn on start at login when it replaces a copy in Applications: turn it on afterwards from the menu, or with omac login on.
  • Update: Omac updates itself. Choose Check for Updates… in its menu, or tick Check for updates automatically there to have it check at most once a day. To update by hand instead, quit Omac, then download the new zip and replace Omac.app.
  • Uninstall: turn off Launch at login in Omac's menu (or in System Settings → General → Login Items) if it is on, quit Omac, then drag Omac.app to the Trash; the complete uninstall lists what else Omac wrote.
  • Every way to install, side by side: Install.
