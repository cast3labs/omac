# Omac

A tiling window manager for macOS. Your windows arrange themselves side by
side instead of piling up, and you move between them with the keyboard. It works
with [Omarchy](https://omarchy.org)'s keybindings. Website:
[omac.ghostype.ca](https://omac.ghostype.ca).

## Private beta

**Omac is in private beta.** Public downloads open with the first release.
Until then there is nothing to install from this repository.

To follow along, watch this repository for its releases (**Watch → Custom →
Releases**), or visit [omac.ghostype.ca](https://omac.ghostype.ca).

Still have an earlier preview of Omac? It keeps working as it is. To remove it,
follow [the uninstall steps](https://omac.ghostype.ca/install/#uninstall).
